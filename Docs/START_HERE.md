# PERSONA — старт проекта

Unreal Engine **5.8.3**, Windows x64, C++ и Blueprints. Репозиторий содержит исходники,
импортированного PERSONA, хаб и испытательный стенд. Текущее состояние проверок — в `VERIFICATION.md`.

## Запуск и сборка

1. Запустить `Scripts/Build.ps1` из PowerShell для сборки редакторского модуля.
2. Открыть `PersonaTrial.uproject`. Начальная карта — `L_Hub`.
3. Для локальных сетевых проверок запустить `Scripts/RunLocal.ps1 -Players 4 -Visible`.
   Для задержки и потерь добавить `-NetworkEmulation`. Завершение тестовых процессов — `Scripts/StopLocal.ps1`.
4. `Scripts/Package.ps1` собирает Windows Development в `Artifacts/Windows`.

Готовая игра запускается без редактора через `Artifacts/Windows/Start_Local.cmd`.
Он открывает одиночный хаб; для сетевой игры нажать Host в панели Tab, а на другом ПК
подключиться через `PersonaJoinIP адрес:7777`. Для Steam использовать `Start_Steam.cmd`
при запущенном клиенте Steam. Переносить на другой ПК всю папку `Artifacts/Windows`.

Путь UE определяется через зарегистрированную установку. На другой машине передать
`-PersonaEngineRoot 'путь к UE_5.8'` соответствующему скрипту.
Для сборки нужны Visual Studio Build Tools 2022, MSVC 14.44.35229 (или совместимое исправление
ветки 14.44), Windows SDK 22621, .NET Framework 4.8 SDK/Targeting Pack и Git LFS.
Для запуска готовой сборки Build Tools не нужны.
После клонирования выполнить `git lfs pull`.

## Управление

| Клавиши | Действие |
|---|---|
| WASD / мышь | Перемещение и обзор |
| Shift / Ctrl / пробел | Бег / приседание / прыжок |
| E | Использовать, поднять или отпустить |
| Q | Бросить переносимый предмет |
| V | Удерживать для голосовой передачи |
| Tab | Панель сессии, участников и тестовых функций |

Для перехода в испытание участники отмечают готовность. Хост запускает переход кнопкой
или терминалом. В хабе можно выбрать кооператив либо 2×2. Предусмотрен дружественный огонь;
настройка `bFriendlyFire` находится в конфигурации GameMode. Игроки обеих команд слышат соседей.

## Steam

По умолчанию активны OnlineSubsystemSteam и SteamSockets, временный App ID **480**.
Хост создаёт сессию, остальные находят совместимую сессию или принимают приглашение через Steam.
Фильтры проекта и версии обязательны, поскольку App ID общий для множества разработчиков.

Проверка настоящего Steam-подключения и VOIP требует двух компьютеров и разных Steam-аккаунтов.
Запустить Steam до Development-сборки. Скрипт упаковки создаёт рядом с exe
`steam_appid.txt` с содержимым `480`; файл исключён из Git. Перед выпуском заменить тестовый ID
собственным и отдельно подготовить Steamworks. Этот проект ничего не публикует.

`-CustomConfig=Local -nosteam` выбирает Null/IP-профиль. Несколько локальных процессов не
являются проверкой голосового чата Steam. Если хост выходит, сессия заканчивается; миграции хоста нет.

## Архитектура

- `PersonaFramework`: GameMode принимает авторитетные решения, GameState реплицирует режим и фазу,
  PlayerState хранит команду, готовность и GAS-атрибуты. Контроллер управляет локальной панелью и голосом.
- `PersonaOnline`: жизненный цикл сессий и приглашения. Локальный и Steam-профили используют разные драйверы.
- `PersonaCharacter` / `PersonaAnimation`: сетевое перемещение, полный персонаж, руки первого лица,
  перенос анимаций и корректирующие формы. Animation Blueprint хранит доступные для настройки клипы.
- `PersonaInteraction`: общий интерфейс, серверная проверка луча взаимодействия, владелец предмета,
  освобождение при отключении, двери и терминалы. Физика предмета авторитетна на сервере.
- `PersonaAttributes`: GAS, здоровье, выносливость и сытость 0–100. Голодная шкала означает запас питания:
  100 — сыт. Реалистичный метаболизм будет отдельной системой; на стенде доступны тестовые воздействия.
- `PersonaAI`: серверные зрение и слух, Behavior Tree с патрулированием, исследованием шума и преследованием.
  Шум создают шаги и взаимодействия, а не микрофон. Частота принятия решений — 4 раза в секунду.

Один NPC автоматически появляется в испытании; хост может выбрать 1, 10 или 30 через панель.
NPC используют PERSONA с тёмным материалом. Их простой контактный урон служит проверкой здоровья,
а не завершённой боевой системой. Консольные команды: `PersonaNPCs 30`, `PersonaReady`,
`PersonaTrial`, `PersonaHub`, `PersonaMode 1`, `PersonaJoinIP 127.0.0.1:7777`.

## Следующие этапы

Полноценные испытания, оружие и ближний бой, повреждения частей тела, питание,
перенос товарищей, сложное поведение NPC и постоянная прогрессия развиваются поверх этой основы.
Текущая версия не включает выделенные серверы, облачные сохранения и релизную защиту от читов.
