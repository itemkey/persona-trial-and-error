# PERSONA — игра с другом через интернет

## Скачать и запустить

1. Оба игрока скачивают один и тот же архив `Persona-Windows-playtest-2026-11-02.zip` из раздела Releases репозитория `itemkey/persona-trial-and-error` на GitHub. Автоматические архивы `Source code` содержат исходники, а не готовую игру.
2. Полностью распакуйте ZIP в отдельную папку. Unreal Engine, Visual Studio и Git устанавливать не нужно.
3. Запустите Steam, войдите каждый в свой аккаунт и добавьте друг друга в друзья. Steam должен оставаться запущенным во время игры.
4. В папке распакованной игры откройте `Start_Steam.cmd`. Если Windows сообщает об отсутствии компонентов Visual C++, запустите `Install_Prerequisites.cmd`, завершите установку и повторите запуск игры.

## Создать сектор и подключить друга

1. Хост выбирает «Направление в новый сектор» → «Совместное испытание · до 4 участников» и ждёт загрузки сектора.
2. Друг выбирает «Перевод в действующий сектор» → «Повторить поиск» и нажимает строку с именем хоста. Заголовок поиска должен содержать `STEAM`.
3. Если сектор не появился в поиске, хост открывает панель клавишей **Tab**, нажимает **Invite Steam friends** и отправляет приглашение. Друг принимает его в Steam, находясь в главном меню игры.
4. Для продолжения сохранённого сектора хост использует «Проследовать в личный сектор». После загрузки друг подключается снова.

Сектор сохраняется на компьютере хоста. Выход хоста завершает общую сессию. Выходите через меню игры, чтобы сохранить прогресс.

## Если не подключается

- Проверьте, что у обоих одна и та же сборка и игра запущена именно через `Start_Steam.cmd`. `Start_Local.cmd` отключает Steam и предназначен для локальной сети.
- Если в поиске написано «ЛОКАЛЬНАЯ СЕТЬ», закройте игру, убедитесь, что Steam открыт и вошёл в аккаунт, затем повторите запуск через `Start_Steam.cmd`.
- При запросе брандмауэра Windows разрешите сетевой доступ игре. Не отключайте брандмауэр целиком.
- Если поиск пуст, используйте приглашение из панели Tab. При тестировании используются Steam AppID 480 и собственный фильтр сессий PERSONA.
- Если не удалось соединиться, сохраните последние файлы из `PersonaTrial/Saved/Logs` у обоих игроков для диагностики. Подключение двух разных компьютеров через интернет требует совместной проверки с другом.

## Управление

- **WASD** — движение; **мышь** — обзор; **E** — взаимодействие и подбор.
- **1–3** — слоты; **G** — отпустить предмет или поставить кастрюлю на выбранную свободную конфорку.
- **R** — вставить патрон; **F** — передёрнуть помпу; **ЛКМ** — выстрел; **ПКМ** — прицеливание.
- **Tab** — игровая панель; **Esc** — меню.

## Для автора: повторная сборка

Перед `Scripts/Package.ps1` закройте игру и Unreal Editor обычным выходом. Ошибка `Unable to build while Live Coding is active` означает, что редактор или запущенная из него игра удерживают сборку. Скрипт теперь проверяет это до запуска упаковки.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "E:\github\persona-trial-and-error\Scripts\Package.ps1"
```

Готовые файлы появляются в `Artifacts/Windows`. При раздаче сборки не включайте личные сохранения, профили, логи, диагностические снимки и файлы `.pdb`.
